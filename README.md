# The Village

Proof-of-concept website for a midwife-led community hub in Brighouse. Plain static site: no build step.

- `index.html` – page content
- `styles.css` – styles
- `script.js` – session filters, name picker and (prototype-only) interest form

## Run locally

    python3 -m http.server 8000

then open http://localhost:8000.

## Host on GitHub Pages

Repo Settings → Pages → Deploy from branch → `main` / root.
